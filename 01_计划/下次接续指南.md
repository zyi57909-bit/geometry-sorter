## 3 日常改动的五步（仓库已开分支保护，必须走 PR）

```powershell
git pull                                    # 1 先拿最新
git switch -c feat/ams-none-branch          # 2 建自己的分支
#   ...改文件...
.\10_主控_Arduino\compile.ps1               # 3 编译验收（0 错 0 警告才算过）
git add -A
git commit -m "feat(ams): NONE 特判 + r==0 重试计数"   # 4 提交（一次只做一件事）
git push -u origin HEAD                     # 5 推上去 → 网页开 PR → Squash and merge
```

合并后回主干：`git switch main && git pull`。
紧急绕过（要说明原因）：`ALLOW_MAIN_PUSH=1 git push`。

## 4 现在该干什么（进度看板 §8 的依赖顺序）

| 顺序 | 事项 | 关键点 |

## 5 三条别忘的纪律

1. **接口事实只认 `00_接口约定/`**。代码和它冲突时二选一，不许"两份都算对"。
2. **`30_HMI_串口屏/`、`20_视觉_K230/` 只读**，那是两位同学的交付物收件箱，别替他们改。
3. **`90_` / `91_` 只读**，要旧版本用 `git show v0.1-baseline:<路径>`，不要编译旧程序。

## 6 常见卡点速查

| 现象 | 处理 |
|---|---|
| `compile.ps1` 报 `arduino-cli not found` | 装到 `%LOCALAPPDATA%\Programs\arduino-cli\` 或加进 PATH |
| 提示 `AccelStepper.h: No such file` | `arduino-cli lib install AccelStepper@1.64` |
| push 被拒（main 保护） | 正常，改走分支 + PR |
| push 报 403 / 要求登录 | `git config --global credential.helper manager` 后重推；或用 GitHub Desktop |
| `ji.HMI` 读不了 / 入库失败 | 有进程（TJC 软件、预览）占着文件，先关掉；**仓库别放 OneDrive** |
| 串口烧不进去 | 关掉占用 COM 的串口助手；Mega 选 `arduino:avr:mega` |
| 忘了改到哪一步 | 只信 `01_计划/进度看板.md` §1/§5 的状态列，不要凭记忆 |
