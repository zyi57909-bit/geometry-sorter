## 三条铁律

1. **接口事实只认 `00_`**。代码与 `00_` 冲突时，要么改代码，要么走变更流程改 `00_`；不允许"两份都算对"。
2. **`91_` 是快照，不是现状**。AI 总结已核出十余处与代码不符（清单见 `01_计划/进度看板.md` §3），引用前先看 `00_`。
3. **`90_` 只读**。旧程序/旧日志留证据，不编译、不修改；要旧版本用 `git show v0.1-baseline:<路径>`。
