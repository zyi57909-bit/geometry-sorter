## 1 控件清单（当前版本，共 11 个）

| objname    | 类别       | 决定性证据                                                                                                                      | 用途                           |
| ---------- | -------- | -------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| `page0`    | 页面       | `objname→page0`                                                                                                            | 唯一页面（第 0 页）                  |
| `t0`       | **文本控件** | 属性表含 `txt` / `txt_maxl`，**无 `val`**                                                                                        | 状态文本（主控只发 `t0.txt`）          |
| `t1`       | **文本控件** | 同上（属性表逐项：`sta/style/key/borderc/borderw/font/bco/picc/pic/pco/xcen/ycen/pw/txt/txt_maxl/isbr/spax/spay/codesdown/codesup`） | 本应是颜色编号 1..13 → **必须改成数字控件** |
| `t2`       | **文本控件** | 同上                                                                                                                         | 本应是形状编号 1..31 → **必须改成数字控件** |
| `p0`..`p5` | 图片控件     | 各含 `pic`/`picc` 属性                                                                                                         | 主控 0 次调用（死代码）                |
| `data0`    | 数据记录     | `objname→data0`                                                                                                            | 主控 0 次调用（死代码）                |

- **整个工程里没有任何数字控件**（属性表含 `val` 的对象为 0 个）→ 主控发 `t1.val=12` 一定无效，屏上数字永远不动
- 文件里存在两套控件清单：一套只有 `p0..p5` + `page0` + `data0`（旧版，无 `t0/t1/t2`），一套 11 个全的（新版）；**两套新版副本中 `t1/t2` 都还是文本控件**

## 2 `Program.s` 配置（共 3 份，内容除 baud 外一致）

| #   | baud       | dim | recmod | 上电 printh                            |

| 1   | **115200** | 100 | 0      | `00 00 00 ff ff ff 88 ff ff ff`（9 B） |
| 2   | **9600**   | 100 | 0      | 同上（逐字节一致）                            |
| 3   | **115200** | 100 | 0      | 同上                                   |

- 三份都 `dim=100`、`recmod=0`

## 4 对主控的影响（可直接执行）

1. **`t1/t2` 必须改成数字控件、objname 保持 `t1/t2`** → 主控零改动（主控发的是 `t1.val=` / `t2.val=`）
2. **`t0` 保持文本控件**（主控发 `t0.txt="DETECT"`），能容下 6 个英文字符即可
3. 三个控件必须在**上电默认页**（`page0`，已确认只有一个页面，风险低）
4. 实际烧录 baud 必须是 **9600**（主控 `Serial1` 固定 9600）；若改成 115200，主控需同步改一行并在 `00_接口约定/接口约定单.md` 登记
5. `p0..p5` / `data0` 本轮不动
